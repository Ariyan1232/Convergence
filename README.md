# 🌍 Convergence

> **Convergence** is a collaborative travel planning platform that transforms multiple individual itineraries into a single optimized group trip. By intelligently analyzing each traveler's preferences, budget, and schedule, Convergence recommends flights and accommodations that maximize satisfaction across the entire group.

---

## ✨ Features

- 🤝 **Collaborative Trip Planning** – Invite friends to contribute their preferred destinations, dates, budgets, and travel preferences.
- ✈️ **Flight Optimization** – Finds flight combinations that best satisfy each group member's constraints while minimizing overall travel inconvenience.
